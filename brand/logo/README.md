# Blitterbox logo assets

All marks use viewBox `40 66 104 142`, stroke `#121212` 2px, round joins.
Face rule: top `#FFFFFF`, front/left `#D4FF3A`, side/right `#121212` (reversed: `#2E2E2E`, stroke `#EFEDE6`).

| File | Use |
|---|---|
| mark.svg | Primary mark: 8 isometric 1m blocks forming a square ring with an open center |
| mark-reversed.svg | Mark on graphite (#121212) grounds |
| favicon.svg | Flat mark for anything under 24px |
| assembly-01-base.svg | Motion frame 1, 0.0s: bottom row of 3 blocks |
| assembly-02-sides.svg | Motion frame 2, 0.36s: side columns rise |
| assembly-03-locked.svg | Motion frame 3, 0.84s: all 8 blocks, identical to mark.svg |

## Logo animation (LogoClip)
1. base → sides → locked → wordmark at 1.2s.
2. Each block drops in from above over 120ms, firm ease-out, no bounce, staggered about 120ms.
3. Built, not revealed: no fades, wipes, glows or shadows.
4. Final frame: wordmark "blitterbox", Bricolage Grotesque 800, lowercase, -1.5% tracking, never tighter. Chartreuse on graphite, or graphite on vellum (#EFEDE6).
5. Labels type in afterward in JetBrains Mono, character by character.
